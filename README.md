# 잿빛 세월

React, TypeScript, Vite 기반의 다크 판타지 인생 시뮬레이터 프로토타입입니다. 별도 API 키 없이 로컬 규칙 엔진으로 한 생을 플레이할 수 있습니다.

## 실행

```sh
npm.cmd install
npm.cmd run dev
```

개발 서버가 출력하는 로컬 주소를 브라우저에서 엽니다. 테스트와 프로덕션 빌드는 다음 명령으로 실행합니다.

```sh
npm.cmd test
npm.cmd run build
```

## 플레이

출생 기록에서 생애를 시작하고, 사건마다 선택지를 고릅니다. 판정은 D20에 능력 수정치와 숙련 보정을 더해 DC와 비교합니다. 한 달 진행, 다음 사건까지 진행, 1x~16x 자동 진행을 사용할 수 있으며 사건이 열리면 시간이 멈춥니다. 진행 상태는 브라우저 localStorage에 저장됩니다.

## 범위

현재 이벤트는 규칙 기반으로만 생성됩니다. AI 프록시/API 연결, 복수 생애 아카이브, 밸런스 자동 시뮬레이션은 후속 작업입니다.
